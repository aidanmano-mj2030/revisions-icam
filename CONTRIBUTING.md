# Contribuer

1. `git pull` sur `main`.
2. Créer une branche `prenom/sujet`, par exemple `baptiste/cours-ce-moteurs`.
3. Faire ses modifications, vérifier la page dans un navigateur.
4. Pousser la branche et ouvrir une pull request. Un autre membre relit avant le merge.
   Personne ne pousse directement sur `main`.
5. Ajouter une entrée dans `Revisions ICAM/JOURNAL.md` (OneDrive) : ce qui a été fait,
   le numéro de la PR, ce qui reste.

Formules : notation LaTeX entre `$...$`, rendue par MathJax.
